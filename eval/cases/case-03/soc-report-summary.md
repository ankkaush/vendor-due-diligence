# Aravex Systems — SOC 2 Report Summary

**Report type:** SOC 2 **Type I**
**Trust service criteria:** Security
**Report date:** 2025-03-01 (point-in-time assessment; not a period)
**Auditor opinion:** Unqualified

## Note on scope

This report expresses an opinion on whether Aravex's controls were
**suitably designed** as of the report date. It does not express an
opinion on the **operating effectiveness** of those controls over any
period of time. This is Aravex's first SOC 2 examination; no prior-period
report exists.

## Tested Controls (excerpt)

- **Encryption at rest:** Customer data is encrypted using AES-256.
  Design assessed as suitable as of the report date.
- **Encryption in transit:** TLS 1.2 or higher is enforced on
  customer-facing endpoints. Design assessed as suitable as of the report
  date.
