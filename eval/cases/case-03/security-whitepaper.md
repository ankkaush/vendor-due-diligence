# Aravex Systems — Security Whitepaper

**Version:** 2.3
**Published:** 2025-09-01

## Our Certification

Aravex has maintained SOC 2 Type II certification, demonstrating the
continued operating effectiveness of our security program over time. We
believe this reflects our long-standing commitment to security rigor.

## Encryption

All customer data at rest is encrypted using AES-256. Data in transit is
protected using TLS 1.2 or higher.
