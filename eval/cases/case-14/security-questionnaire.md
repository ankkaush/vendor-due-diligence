# Osprey Data Systems — Security Questionnaire

**Date:** 2025-10-01

## Section 1 — Data Residency

**Q1. In which regions is customer data processed and stored?**
Customer data is processed and stored in the United States and European
Union only, using data centers with equivalent security controls in both
regions.

## Section 2 — Data Protection

**Q2. How is customer data protected at rest?**
Customer data at rest is encrypted using AES-256.
