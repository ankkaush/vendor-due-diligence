# Northwind Cloud Systems — SOC 2 Type II Report Summary

**Report type:** SOC 2 Type II
**Trust service criteria:** Security, Availability
**Audit period:** 2024-10-01 to 2025-09-30
**Auditor opinion:** Unqualified

## Section 2 — Scope

This report covers the Northwind Cloud Platform production environment,
including data storage, application, and network infrastructure layers.

## Section 3 — Tested Controls (excerpt)

- **Encryption at rest:** Customer data stored in the production database
  and object storage tiers is encrypted using AES-256. Control operated
  effectively throughout the audit period.
- **Vulnerability and penetration testing:** An independent third-party
  penetration test of the production environment is performed annually.
  The most recent test was completed 2025-06-15. Control operated
  effectively throughout the audit period.
- **Access control:** Production access is restricted via role-based
  access control with quarterly access reviews. Control operated
  effectively throughout the audit period.

No exceptions were noted for the controls listed above during the audit
period.
