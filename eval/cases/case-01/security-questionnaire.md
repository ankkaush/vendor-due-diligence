# Northwind Cloud Systems — Security Questionnaire

**Prepared for:** Prospective customer due-diligence review
**Date:** 2025-10-02

## Section 1 — Certifications

**Q1. Does Northwind hold current third-party security certifications?**
Yes. Northwind has completed a SOC 2 Type II examination covering the
Security and Availability trust service criteria. See the attached SOC 2
report summary for the current audit period.

## Section 2 — Data Protection

**Q2. How is customer data protected at rest?**
All customer data at rest is encrypted using AES-256. Encryption keys are
managed through a dedicated key management service with access restricted
to the platform security team.

**Q3. Does Northwind undergo independent penetration testing?**
Yes, Northwind engages an independent third-party firm to perform a
penetration test of the production environment on an annual basis. See the
attached SOC 2 report summary, which lists this as a tested control.

## Section 3 — Monitoring

**Q4. Does Northwind provide continuous security monitoring?**
Yes. Northwind's Security Operations function provides 24/7 monitoring of
production systems for security events.
