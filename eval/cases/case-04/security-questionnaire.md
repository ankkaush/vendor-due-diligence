# Helion Software — Security Questionnaire

**Date:** 2025-08-19

## Section 1 — Testing

**Q1. Does Helion undergo independent penetration testing?**
Yes, Helion engages a third-party firm to perform an annual penetration
test of our production environment.

## Section 2 — Data Protection

**Q2. How is customer data protected at rest?**
Customer data at rest is encrypted using AES-256.

## Section 3 — Access Control

**Q3. How is production access restricted?**
Production access requires multi-factor authentication and is limited to
engineering personnel via role-based access control.
