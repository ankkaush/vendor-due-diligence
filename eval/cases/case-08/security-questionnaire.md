# Quillan Data Co. — Security Questionnaire

**Date:** 2025-09-05

## Section 1 — Data Residency

**Q1. Where is customer data processed and stored?**
All customer data is processed and stored exclusively within European
Union data centers. Quillan does not transfer or process customer data
outside the EU.

## Section 2 — Data Protection

**Q2. How is customer data protected at rest?**
Customer data at rest is encrypted using AES-256.
