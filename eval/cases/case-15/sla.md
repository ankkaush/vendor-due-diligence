# Thornbury Cloud — Service Level Agreement (v2)

**Effective date:** 2025-08-01
*(This SLA supersedes v1, dated 2023-11-01, which is not attached to this
submission.)*

## Section 2 — Availability and Data Protection Commitments

Thornbury commits to 99.99% monthly uptime and hourly encrypted backups
of all production data, supported by an expanded security control set
implemented since the prior SLA version.
