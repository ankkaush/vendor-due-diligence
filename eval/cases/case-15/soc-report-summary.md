# Thornbury Cloud — SOC 2 Type II Report Summary

**Report type:** SOC 2 Type II
**Trust service criteria:** Security, Availability
**Audit period:** 2023-01-01 to 2023-06-30
**Auditor opinion:** Unqualified

## Tested Controls (excerpt)

- **Backup:** Production data is backed up on a daily basis to redundant
  storage. Control operated effectively throughout the audit period.
- **Availability monitoring:** Uptime is monitored continuously against
  an internal target. Control operated effectively throughout the audit
  period.

No exceptions were noted for the controls listed above during the audit
period. This report does not reflect any control changes made after
2023-06-30.
