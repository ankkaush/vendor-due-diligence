# Vantree Technologies — Security Questionnaire

**Date:** 2025-09-12

## Section 1 — Transport Security (Technical Detail)

**Q1. What TLS/SSL protocol versions are supported on customer-facing
endpoints?**
For backward compatibility with certain legacy enterprise clients,
Vantree supports TLS 1.0 and TLS 1.2 on customer-facing endpoints. TLS
1.0 support is scheduled for deprecation in a future release.

**Q2. What encryption is used for data at rest?**
Data at rest is encrypted using AES-256.
