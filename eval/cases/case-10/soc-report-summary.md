# Ashgrove Systems — SOC 2 Type II Report Summary

**Report type:** SOC 2 Type II
**Trust service criteria:** Security
**Audit period:** 2025-01-01 to 2025-06-30
**Auditor opinion:** Unqualified

## Tested Controls (excerpt)

- **Encryption at rest:** Customer data is encrypted using AES-256 via a
  dedicated key management service. Control operated effectively
  throughout the audit period.
- **Change management:** Production changes require peer review and
  approval prior to deployment. Control operated effectively throughout
  the audit period.

No exceptions were noted for the controls listed above during the audit
period.
